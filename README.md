# Классификация спутниковых снимков EuroSAT (13 спектральных каналов)

Проект по классификации спутниковых снимков EuroSAT с использованием 13 спектральных каналов (включая инфракрасные). Сравниваются две самописные CNN архитектуры: без Dropout и с Dropout. Лучшая модель достигла F1-score 0.969 (96.9%).

**Ссылка на датасет:** [EuroSAT (13 bands)](https://www.kaggle.com/datasets/apollo2506/eurosat-dataset?select=EuroSATallBands)

---

## Этапы работы

**Технологии:** Python, PyTorch, Torchvision, Scikit-learn, Tifffile, NumPy, Matplotlib, Seaborn, tqdm

### 1. **Загрузка и анализ данных**
   - Датасет: 27 595 спутниковых изображений (train + val + test)
   - 10 классов земной поверхности (лес, река, город, поля и др.)
   - Формат: 64×64 пикселя, 13 спектральных каналов (включая NIR)
   - Файлы: многоканальные TIFF

### 2. **Предобработка данных**
   - Кастомный Dataset для чтения 13-канальных TIFF
   - Нормализация: для каждого канала отдельно (mean=0, std=1)
   - DataLoader: batch_size=32, shuffle=True для train
   - Разбиение данных уже готово (train.csv, val.csv, test.csv)

### 3. **Моделирование**
   Сравнила 2 архитектуры (обе с 13 каналами на входе):
   - **Model1:** 3 сверточных слоя (64 -> 128 -> 256) + AdaptiveAvgPool2d + Dropout(0.3)
   - **Model2:** аналогичная архитектура с дополнительными Dropout после сверток (0.1, 0.2, 0.2, 0.4)

### 4. **Обучение**
   - 25 эпох, early stopping (patience=5)
   - Оптимизатор: Adam (lr=0.0005, weight_decay=1e-4)
   - Scheduler: ReduceLROnPlateau (mode='max', factor=0.5, patience=3)
   - Функция потерь: CrossEntropyLoss

## Почему 13 каналов вместо 3

Обычная камера видит только видимый свет (RGB). Спутник Sentinel-2 снимает в **13 спектральных каналах**, включая:
- **Инфракрасный (NIR)** - показывает здоровье растений
- **Красная граница (Red Edge)** - важна для сельского хозяйства
- **Коротковолновый инфракрасный (SWIR)** - для анализа почвы и влажности

Это позволяет различать типы растительности, которые выглядят одинаково в RGB.

**Ключевые особенности:**
- `AdaptiveAvgPool2d` — не зависит от размера карты признаков
- 10 классов на выходе
- Всего 2.48M параметров

---

## Что я узнала

1. **13 каналов дают преимущество:** Модель научилась различать типы растительности (PermanentCrop vs AnnualCrop), что сложно сделать только в RGB

2. **Dropout не всегда улучшает результат:** Model1 (без Dropout в свертках) показала результат **0.969** против 0.965 у Model2

3. **AdaptiveAvgPool2d удобен:** Позволяет менять архитектуру, не пересчитывая размер перед Linear слоем

4. **Early stopping эффективен:** Обе модели стабилизировались к 20-25 эпохе, дальнейшее обучение не дало прироста

5. **PermanentCrop - самый сложный класс:** Многолетние культуры визуально похожи на однолетние (AnnualCrop), требуется больше данных или аугментация
